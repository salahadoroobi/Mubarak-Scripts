# Mubarak Scripts

مستودع لإدارة مشغّل Lua للأجهزة المصرّح لها.

## الملفات
- `Mubarak.lua`: مشغّل GameGuardian يتحقق من معرّف الجهاز ويحمّل السكربت المشفّر.
- `users.txt`: معرّفات الأجهزة المصرّح لها، معرّف واحد في كل سطر.
- `script_encrypted.txt`: ملف مطلوب للتشغيل، **لم يُرفع بعد**.

## ملاحظات
- ملف `script_encrypted.txt` يجب أن يكون نصاً سداسياً (Hex) ناتجاً عن XOR لكل بايت من مصدر Lua باستخدام المفتاح 117.
- `boot_id` قد يتغير عند إعادة التشغيل، لذا ليس معرّفاً دائماً.
- لا ترفع أسراراً أو بيانات حساسة إلى مستودع عام.
- لا تنسخ سكربتات طرف ثالث دون تصريح بإعادة الاستضافة.
